## 实现范围

- Astro Content Collections 管理 `blog` 与 `project` 两个集合，支持 MDX、成长状态与归档字段。
- 浅色/深色主题切换，`localStorage` 持久化，渲染前应用主题避免闪烁。
- SEO 基础：正式域名 canonical、Open Graph、RSS、robots.txt、sitemap、favicon。
- 自定义 404 页面，不存在的路由返回真实 HTTP 404。
- Playwright + axe 自动化测试：13 个页面的渲染、横向溢出、可访问性、主题持久化、链接可达性检查。

## 部署形态

静态构建产物通过 Cloudflare Workers 静态资源托管：`pnpm run build` 生成 `dist/`，`npx wrangler deploy` 发布，自定义域名 `blog.liuguangzhong.top` 已绑定并启用 HTTPS，仓库 `main` 分支保持与线上一致。

## 当前边界

`*.pages.dev` 类默认地址未经确认，站点唯一经过验收的入口是正式域名；Cloudflare 自动注入的 Web Analytics 脚本在部分受限网络下无法加载，会影响该客户端的访问统计，但不影响站点本身的任何功能。
