## 实现范围

- 解析 KiCad S-expression 和 XML 两种网表格式。
- 将元件、引脚和网络关系建模为可查询的数据结构。
- 识别常见 LDO、TVS/ESD 器件与去耦电容。
- 检查连接关系和电容阈值，并通过 Pydantic 输出结构化结果。
- 提供 JSON-RPC 与 FastMCP 接口，方便其他工具调用分析能力。
